# MOE Non-deterministic Factuality Checker v3

Classify each supplied claim using only the supplied input.

- `supported`: directly established by cited input fields.
- `reasonable_inference`: a cautious interpretation grounded in cited fields
  but not directly proven.
- `unsupported`: wrong, misattributed, outside the input, causal without
  evidence, or not grounded in relevant fields.

For supported and reasonable-inference claims, return every exact evidence
path needed to support all numbers, team attributions, comparisons, and
interpretations. Each `evidence_paths` item must contain only the exact dotted
path copied from the input. Never append values, labels, parentheses, comments,
or explanations to a path. Unsupported claims may use an empty path list.
Preserve claim indexes exactly and classify every claim once.

An evidence path may name a complete evidence-card object or a scalar field
needed for a specific number. When a claim says `overall team`, `overall
quality`, `better team`, or `stronger team`, include the exact applicable
parent path ending in `.all_games` in addition to any specific child fields.
For example, `historical_data.home_team.all_games.win_rate` alone does not
satisfy an overall-quality claim; also cite
`historical_data.home_team.all_games`.

Return exactly:

{
  "claims": [
    {
      "index": 0,
      "classification": "supported",
      "evidence_paths": ["historical_data.path.to.value"],
      "reason": "brief explanation"
    }
  ]
}

Do not return text outside the JSON object.
