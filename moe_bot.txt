MOE CHANNEL VIEW PLAN
=====================

Decision recorded 2026-09-08
----------------------------

Focus on fixing the existing private MOE supergroup and its Review, Picks, and
Scores topics. Leave the current NFL Guesser private-chat behavior unchanged
at this stage, including its existing MOE navigation. Removing that navigation
can be a later product decision after the channel view is complete.

Use the existing @nflguesser_bot identity as the Telegram transport for both
products. Product separation comes from strict chat scoping, not from a second
bot identity:

- NFL Guesser private chats keep their complete current behavior.
- The MOE supergroup gets its own channel-native cards and interactions.
- MOE group handlers run only when the chat ID equals MOE_DESK_CHAT_ID.

The separately registered @nfl_moe_bot is no longer part of the target
architecture. Keep it stopped until the shared-bot design is verified, then
remove it from the group, delete it through BotFather, and clear its token.

Picks implementation status
---------------------------

- Compact game cards render both God arms and every approved expert conclusion
  directly from the persisted Sheet rows.
- Consensus counts actual side selections and excludes side PASS rows.
- Show full opinions edits the existing card into a paginated opinion reader.
- Previous, Next, and Back to picks remain restricted to the MOE group.
- Full persisted opinions are split safely into same-card pages.
- Existing @nflguesser_bot-owned Picks cards are edited in place.
- Review, Scores, and NFL Guesser private views remain unchanged.
- Local validation and live-data rendering are complete; deployment restart
  waits for approval of the exact card preview.


WHY ONE BOT
===========

Telegram capabilities do not improve with a second bot. The existing bot can:

- Post, edit, delete, and pin MOE cards.
- Handle review and view callbacks.
- Post into the configured forum topics.
- Reuse the message IDs it already owns.

A second bot adds another token, session, systemd unit, state namespace,
administrator identity, deployment path, and failure mode. It also cannot edit
the existing @nflguesser_bot-owned cards, forcing a noisy replacement wave.

Using the same identity avoids that migration and still keeps the products
separate because Telegram handlers can be restricted by chat and topic.


SOURCE OF TRUTH
===============

The MOE channel view reads existing persisted data. It must not depend on an
NFL Guesser private-chat view or rerun an expert prompt.

Inputs:

- nfl_games: matchup, week, kickoff, and status.
- moe_opinions: generated opinions, picks, confidence, full explanations,
  review metadata, hashes, expert versions, and model information.
- allowed_users: reviewer identity and role.
- team_emojis: display metadata.
- moe/experts.yaml: expert names, modes, and committee policy.

Rendering and synchronization belong in moe_desk.py. The Telegram runtime may
live in intake_bot.py because the same bot connection is already running, but
the MOE model and renderers remain separate from NFL Guesser private views.

Google Sheets remains the source of truth. Repo prompt files remain generation
instructions and version history; they are not channel-view storage.

TARGET CHANNEL EXPERIENCE
=========================

Picks topic
-----------

Maintain one compact primary card per game. It should show:

- Matchup and kickoff.
- God Rules and God Judge side/total decisions.
- One concise row per approved expert.
- Pick or predicted winner, confidence stars, probability, and projected score
  when available.
- Committee agreement/disagreement at a glance.
- Clear pending/missing state for God arms.

Do not automatically publish every full explanation during initial sync.

Add channel-local controls:

- Show full opinions
- Previous / Next
- Back to picks

Show full opinions edits the existing game card to display the first persisted
opinion page. Previous and Next edit that same card through every expert and
long-text chunk. Back to picks restores the compact committee summary. No
additional Telegram messages are created.

Long details must:

- Prefer full_opinion when present.
- Fall back to structured thesis/support/counterargument fields.
- Split below Telegram's 4096-character HTML limit.
- Escape Telegram HTML safely.
- Preserve one expert's sections together where possible.
- Edit the existing game card rather than creating reply messages.
- Never link to an NFL Guesser private chat.

Review topic
------------

Maintain a compact pending queue and one actionable card per game with pending
opinions.

Reviewers need enough information to decide inside the MOE group. Pending
details may also use Show/Hide controls so the topic does not dump every long
opinion automatically.

Review mutations remain:

- Restricted to configured reviewer-role users.
- Hash checked against the persisted output.
- First-decision-wins within the running process and protected against
  sequential overwrites in the store.
- Reflected in the relevant Review and Picks cards on the next synchronization.

Scores topic
------------

Continue posting MOE grading digests in the configured Scores topic. Scores
must use the same bot identity and must not require a private NFL Guesser view.


CHANNEL-SCOPING RULES
=====================

View fixes do not automatically apply to every Telegram channel.

MOE-only changes
----------------

Changes to these surfaces should affect only the configured MOE supergroup:

- moe_desk.py card and detail renderers.
- MOE Review/Picks/Scores synchronization.
- desk: and MOE channel-view callbacks.
- /desk diagnostics.
- MOE message state and topic routing.

Every runtime entry point must verify:

    event.chat_id == MOE_DESK_CHAT_ID

before processing a MOE group command or callback.

NFL Guesser private-chat behavior
---------------------------------

Leave the complete private prediction/intake and existing MOE navigation
experience unchanged for now. Channel-view work must not add, remove, or alter
its buttons, summaries, model pickers, opinion details, or deep links.

The same bot process and token do not imply shared UI. Telegram chat context
determines which handler is allowed to respond.

Shared-data changes
-------------------

Changes to opinion generation, moe_opinions schema, expert registry, approval
integrity, or God policy can affect every consumer of those data. These are not
view-only changes and require separate validation.

Shared-runtime changes
----------------------

Changes to Telegram startup, authentication, generic caching, or process
shutdown can affect both private intake and MOE group behavior. Avoid changing
shared runtime machinery merely to iterate on a card layout.


IMPLEMENTATION PLAN
===================

Phase 1: restore and freeze the working baseline
------------------------------------------------

1. Restore the pre-separation intake/MOE implementation.
2. Keep telegram-intake.service as the only desk writer.
3. Reuse moe_desk_state.json and the existing bot-owned message IDs.
4. Remove the disabled dedicated service unit from the VPS.
5. Leave NFL Guesser private views unchanged while channel work proceeds.
6. Restrict new Show/Hide callbacks to MOE_DESK_CHAT_ID.

Phase 2: redesign the cards
---------------------------

1. Keep primary Review and Picks cards concise.
2. Replace automatic full-detail bundles with same-card pagination.
3. Track the selected opinion page per event.
4. Reconcile the visible page when approved opinions change.
5. Preserve current cards if an edit/send/delete fails; retry on the next pass.
6. Delete stale Picks cards when approvals are revoked.
7. Keep queue/week cards pinned and update them in place.
8. Do not emit a large initial message wave.

Phase 3: tests
--------------

Required coverage:

1. Existing NFL Guesser private views remain byte-for-byte unchanged.
2. Existing NFL Guesser MOE navigation continues to work.
3. New channel-only callbacks are rejected outside MOE_DESK_CHAT_ID.
4. Authorized reviewers can approve/reject in the MOE group.
5. Unauthorized users cannot mutate reviews.
6. Existing @nflguesser_bot-owned cards are edited rather than replaced.
7. Initial synchronization does not auto-post full-opinion bundles.
8. Show full opinions edits the existing card and creates no messages.
9. Previous/Next page through every persisted opinion and long-text chunk.
10. Back to picks restores the compact card.
11. Telegram limits and HTML escaping remain safe.
12. Failed sends, edits, and deletes preserve retryable state.
13. Revoked approvals remove stale Picks content.
14. Scores notices use the configured MOE group/topic.
15. No rendered MOE URL opens an NFL Guesser private chat.

Run the complete MOE and intake regression suite before deployment.

Phase 4: preview and controlled cutover
---------------------------------------

1. Back up the current desk state.
2. Render the exact initial synchronization against live Sheet data without
   posting.
3. Confirm the preview edits existing cards and does not create a bulk detail
   dump.
4. Obtain approval before publishing or editing Telegram messages.
5. Deploy code and restart telegram-intake.service only after all VCS changes
   are complete.
6. Verify the running commit, bot identity, group/topic IDs, permissions,
   reviewer resolution, and recent service logs.
7. Verify one non-mutating Show/Hide path before changing a real review.
8. Verify an approved opinion refreshes only its MOE group card.

Phase 5: remove the unused bot
------------------------------

After the existing bot owns the redesigned MOE experience:

1. Keep moe-bot.service disabled and remove its installed unit.
2. Remove @nfl_moe_bot from the MOE group.
3. Delete @nfl_moe_bot through BotFather.
4. Clear MOE_BOT_TOKEN with the safe environment helper while preserving the
   key set and all other .env.local values.
5. Remove dedicated runtime/service files and documentation from the repo.
6. Preserve environment backups through the rollback window.


WHAT MUST NOT CHANGE
====================

- Opinion generation remains append-only.
- Review writes remain hash checked.
- Approved display rows remain output-hash validated.
- Google Sheets remains the source of truth.
- Existing expert IDs, versions, prompts, and output hashes are not rewritten
  for a view change.
- God policy, committee keys, grading, and generation behavior do not change.
- Reviewer identity continues to come from allowed_users.
- Pending rows are never automatically approved.
- Existing MOE topic IDs remain unchanged.
- NFL Guesser prediction, win-total, celebrity-intake, and suggestion flows
  remain operational.
- No Telegram message is posted or edited before its exact preview is approved.


RISKS AND MITIGATIONS
=====================

Accidental private-chat coupling
--------------------------------

Mitigation: do not restore private MOE routes. Gate every group handler on the
configured MOE chat ID and test the negative path.

Channel clutter
---------------

Mitigation: compact primary cards plus same-card opinion pagination. Never
auto-post a reply bundle during synchronization.

Two desk writers
----------------

Mitigation: moe-bot.service remains stopped. Only telegram-intake.service may
own synchronization after the pivot.

Shared-process failure
----------------------

Mitigation: keep MOE rendering and synchronization errors isolated and logged
so a Sheet or Bot API error does not terminate private intake handling.

State corruption or message loss
--------------------------------

Mitigation: retain message state until Telegram operations succeed, track
obsolete replacement IDs, edit before deleting old copies, and back up state
before deployment.

Unexpected cross-channel effects
--------------------------------

Mitigation: treat moe_desk rendering as MOE-only. Changes to shared data models
or generic runtime code require broader tests and must not be disguised as
card-layout work.


DONE WHEN
=========

1. @nflguesser_bot is the sole active MOE group writer.
2. NFL Guesser private behavior remains unchanged during this phase.
3. Review, Picks, and Scores operate directly inside the MOE supergroup.
4. Primary game cards are compact and existing cards update in place.
5. Full opinions appear as pages in the same card when requested.
6. Back to picks restores the compact summary without creating messages.
7. Review actions remain role-checked and hash-checked.
8. MOE view changes do not alter private NFL Guesser behavior.
9. The dedicated MOE service and bot are removed after verification.
10. Live behavior, state persistence, restart behavior, and rollback have been
    verified.
