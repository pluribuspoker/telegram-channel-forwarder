## Telegram message formatting

- Always pass `msg.entities` through via `formatting_entities=`; never rebuild text without them. `text_suffix` in `send_group` appends without dropping entities.
- **Entities pair with `raw_text`, never `.text`** — `.text` is the markdown render (literal `**`), so pairing it with `formatting_entities=` shifts every entity and leaves stray delimiters. Whatever string goes beside `formatting_entities` must be `raw_text`. (`enrich_caption` keeps `.text` deliberately — that caption is markdown-parsed on send.)
- All content matching (`filter_pattern`, `reply_chain_cappers`, …) must run on `.raw_text` — against `.text` an anchored `^Tony POD` sees `**Tony POD**` and the pick drops with no error.
- Mapping `source_prefix` = bold header line above the forward (`prepend_header` shifts entities by UTF-16 length; it becomes the post's `capper_name`); `source_label` = `— X` suffix. Detail: docs/tracker.md.
- Pinned by `scripts/test_forward_entities_regression.py`.
- **Any edit rebuilt from HTML must use `to_bot_html`/`patch_expandable_blockquotes` (`tracker_format.py`)** — stock Telethon drops the blockquote `collapsed` flag both ways (unparse AND parse), so one bare-`<blockquote>` edit expands a collapsed quote unrecoverably (the flag survives only at the source). Bot API syntax: `<blockquote expandable>`. Pinned by `scripts/test_expandable_blockquote.py`.

## Pick tracker — docs/tracker.md

- `grade` alias = `--days 1`; older picks: `tracker.py --live --days 2`. Targeted: `--target=-100…:ID` (use `=`, repeatable, skips the date scan).
- Fast path: listener enqueues exact targets ~3s after a forward; summary line in `journalctl -u telegram-forwarder`, full output `logs/tracker_quick.log`.
- UNKNOWN is never persisted; ungradeable legs are capped by `should_skip_unknown()`/`record_unknown_attempt()` (`common.py`, shared by daemon+tracker) — 6 tries, 30-min spacing, verdict-less dict with deliberately no `game_date`.
- **The bet-slip image prompt applies only once the image IS a slip** — cappers attach stats cards to every post, and an image with no ticket answered "is this one combined ticket?" with a silent no, demoting a slash parlay to two singles (one leg's price shown as the bet's, each leg graded separately). `_mark_slash_parlay_legs` (`ai.py`) is the deterministic backstop: 2+ standalone picks in different slash segments of one non-blockquote line = parlay legs. Test: `scripts/test_slash_parlay.py`.
- **A one-pick-per-line card is straight bets, never a parlay** — Trent's "CFB MORTAL MEGAS" (5 sides, "5-0 CARD") parsed as 5 parlay legs: a fake [+2309], Michigan's loss "settled the ticket" and voided the other 4 ungraded (2026-10-03). Parlay needs ticket wording, one line combining selections, or a combined price. Prompt rule + deterministic backstop `_demote_unworded_card_parlay` (`ai.py`: all legs parlay, no image, no ticket wording, exactly one bet token per bet line, one line per leg). Test: `scripts/test_card_straights.py`.
- **Teaser legs bet the STATED line** — "7 pt teaser: Eagles PK / Rams +0.5" is PK and +0.5 (PK = spread 0), never stated+7 (the pre-tease misread graded teaser legs ~7 pts too generously; FCS 2026-09-20). Prompt rule + deterministic backstop `_fix_teaser_stated_lines` (`ai.py`, parlay-leg spreads only, runs after `_mark_slash_parlay_legs`, fails open on any segment naming two lines). Test: `scripts/test_teaser_stated_lines.py`.
- **Same-side "spread & ML" = two straight bets, never a 2-leg parlay** — Trent's "VT -2.5 SPREAD & ML" hit the prompt's "X & Y = parlay" rule and `_insert_odds` multiplied -105 × -130 into [+245] (a covered spread IS a win, so no book prices it near the product; 2026-10-02). Deterministic backstop `_split_same_side_spread_ml` (`ai.py`): exactly one spread + one ML leg, same team(s)/period, no parlay/SGP/same-game/teaser/N-leg wording. Test: `scripts/test_same_side_spread_ml.py` (also pins trent_watcher escaping X's pre-escaped `&amp;` once).
- **Bare "TEAM over/under N" = GAME total** — cappers name a team as game shorthand ("Chiefs over 42.5" = Broncos–Chiefs o42.5; a team_total misread prices a deep alternate via the PAID path, [+3500] on a -110 bet, and grades one team's score). team_total needs explicit `team total`/`TT` wording or a team-only-range number. Prompt rule + deterministic backstop `_fix_bare_game_total` (`ai.py`, `_GAME_TOTAL_FLOORS` per sport, full-game period only, Soccer exempt). Test: `scripts/test_bare_game_total.py`.
- Player props: `box_score_text` emits **every** stat group (batting+pitching, passing+rushing, …) as generic `key=value`; prop context includes line scores (NRFI). Player absent from the bound game → slate-wide strict-name box rescue (stale roster memory binds a traded player's OLD team); parse consults the slip image when a player prop's team isn't in the text — the slip's team chip beats roster memory. Test: `scripts/test_box_score_props.py`.
- **A message can MIX parlay legs with standalone picks — the ticket settles, voids, and broadcasts on its `is_parlay_leg` legs ONLY** (`_parlay_lost`/`_ticket_settled`/`_void_moot_parlay_legs`/`_bc_results_for`, `grade_daemon.py`; settledness guard in `broadcast_results`): a standalone sibling resolving neither settles the ticket (the ❓-parlay broadcast, 2026-09-20) nor rides inside it, a lost ticket never voids a live standalone leg (an unplayed pick was killed) or vice versa, and a resolved standalone never WAITS on unresolved siblings — the daemon's broadcast-only mop-up (`_unbroadcast_legs`) flushes externally-graded standalones on partially-resolved messages too (an audit-graded Bucs ❌ sat 19h for the teaser's MNF leg, 2026-09-21). Test: `scripts/test_mixed_parlay_broadcast.py`.
- **Emoji placement must be order-independent** — legs settle in different passes (mid-game totals, period completes, finals) and daemon+tracker interleave edits: same-game sibling lines tie-break on the bet's own number/direction (`_prefer_bet_line`), re-inserting an already-placed verdict is a no-op (`ignore_emoji` probe), identity matches (passes 1–4) place before the pass-5 heuristic. A/B replay can't see these bugs (index order masks them) — sweep by diffing recomputed placement against live `html_text`. Test: `scripts/test_same_game_emoji_placement.py`.
- `audit.record` fingerprints the rendered post and skips identical reposts. The daemon retires entries unresolved 3+ days past the latest **game** date (`GRADE_STALE_UNRESOLVED_DAYS`) — reuses `_failed`, never broadcasts them.
- `verify_picks_on_schedule()` (`scores.py`, fresh parses only) checks every pick against the slate: confirmed / corrected (repair from a raw-message token) / suspect (reported, never auto-corrected) / unverified / n-a. **An ESPN outage must never read as a bad parse.** Adding a sport → note rival promotions in `_RIVAL_PROMOTIONS`.
